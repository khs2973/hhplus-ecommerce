# 상품 조회

```mermaid
sequenceDiagram
    participant Client
    participant Controller as ProductController
    participant Service as ProductService
    participant Repository as ProductRepository

    Client ->> Controller : 상품 조회 요청
    Controller ->> Service : 상품 조회 요청
    Service ->> Repository : 상품 조회 요청

    alt 상품 존재
        Repository -->> Service : 상품 반환
        Service -->> Controller : 상품 반환
        Controller -->> Client : 200 OK
    else 상품 없음
        Repository -->> Service : NULL
        Service -->> Controller : 상품 없음
        Controller -->> Client : "상품을 찾을 수 없습니다."
    end
