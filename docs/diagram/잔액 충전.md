# 잔액 충전

```mermaid
sequenceDiagram
  participant User as User
  participant ChargeController as ChargeController
  participant ChargeService as ChargeService
  participant UserPointRepository as UserPointRepository
  participant PointHistoryRepository as PointHistoryRepository

  User ->> ChargeController: 충전 요청
  ChargeController ->> ChargeService: 충전 요청
  ChargeService ->> UserPointRepository: 사용자 포인트 요청
  UserPointRepository -->> ChargeService: 사용자 포인트 반환
  alt 충전 한도 초과
    ChargeService ->> ChargeService: 포인트 최대 한도 초과
    ChargeService -->> ChargeController: 포인트 최대 한도 초과
    ChargeController -->> User: "최대 충전 한도를 초과했습니다"
  else 정상 충전
    ChargeService ->> UserPointRepository: 포인트 충전
    UserPointRepository -->> ChargeService: 
    ChargeService ->> PointHistoryRepository: 포인트 충전 내역 저장
    PointHistoryRepository -->> ChargeService: 
    ChargeService -->> ChargeController: 포인트 충전 완료
    ChargeController -->> User: "충전이 완료 됐습니다."
  end
