# 상품 주문

```mermaid
sequenceDiagram
    participant User
    participant Controller as OrderController
    participant OrderService as OrderService
    participant ProductRepository as ProductRepository
    participant Repository as OrderRepository
    participant UserPointRepository

    User ->> Controller : 구매 요청
    Controller ->> OrderService : 구매 요청
    OrderService ->> ProductRepository : 상품 재고 조회

    alt 재고 충분
        ProductRepository -->> OrderService : 상품 재고
        OrderService ->> Repository : 주문 요청
        Repository -->> OrderService : 
        OrderService ->> UserPointRepository : 포인트 차감 요청
        UserPointRepository -->> OrderService : 
        OrderService ->> ProductRepository : 재고 차감
        ProductRepository -->> OrderService : 
        OrderService -->> Controller : 주문 완료
        Controller -->> User : 200 OK
    else 재고 부족
        ProductRepository -->> OrderService : 재고 부족
        OrderService -->> Controller : 재고 부족
        Controller -->> User : "재고가 부족합니다."
    end
