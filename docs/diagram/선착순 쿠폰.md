# 선착순 쿠폰

```mermaid
sequenceDiagram
    participant User
    participant CouponController as CouponController
    participant CouponService as CouponService
    participant CouponRepository as CouponRepository

    User ->> CouponController : 쿠폰 발급 요청
    CouponController ->> CouponService : 쿠폰 발급 요청
    CouponService ->> CouponRepository : 쿠폰 조회

    alt 쿠폰 존재
        CouponRepository -->> CouponService : 쿠폰 데이터 전달

        CouponService ->> CouponRepository : 쿠폰 갯수 조회
        CouponRepository -->> CouponService : 

        alt 잔여 쿠폰 수량
            CouponService ->> CouponRepository : 쿠폰 저장
            CouponRepository -->> CouponService : 
            CouponService -->> CouponController : 쿠폰 지급
            CouponController -->> User : 200 OK
        else 쿠폰 소진
            CouponService -->> CouponController : 쿠폰 수량 소진
            CouponController -->> User : 쿠폰 수량 소진
        end

    else 쿠폰이 없는 경우
        CouponRepository -->> CouponService : NULL
        CouponService -->> CouponController : 쿠폰 없음
        CouponController -->> User : 쿠폰 없음
    end
